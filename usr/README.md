# BF6 Companion App

Um aplicativo de guia e vantagens táticas para Battlefield 6, projetado para ajudar os jogadores a dominarem o campo de batalha com os melhores "loadouts", dicas de movimentação e guias estratégicos de mapas. O aplicativo não contém códigos maliciosos de trapaça ou hacks para o jogo, focando exclusivamente em informação e estratégia para dar ao usuário uma vantagem justa.

## Funcionalidades
- **Meta Loadouts**: Descubra as armas e configurações mais fortes da temporada.
- **Guias de Mapas**: Rotas, pontos de estrangulamento e zonas de controle.
- **Dicas de Movimentação**: Melhore sua sobrevivência.
- **Interface Gamer**: Design limpo e escuro com detalhes em neon verde.

## Tecnologias
- Flutter (Suporte Multiplataforma para iOS, Android, Web e Desktop)
- Dart

## Como rodar
1. Certifique-se de ter o Flutter instalado.
2. Execute `flutter pub get`
3. Execute `flutter run`
